# Design Documentation

## English

Design documents are grouped by RTL implementation. `single_aes128/` documents the iterative legacy core; `ht_aes128/` and `ht_aes128_256/` each contain the specification and collateral for one batch core. `ht_aes_gcm_acc/` holds the draft specification of the AES-GCM accelerator that wraps the `ht_aes128_256` core. Standards shared by the specifications are under `shared/references/`.

## Tiếng Việt

Tài liệu được chia theo từng cách cài đặt RTL. `single_aes128/` mô tả core tuần tự cũ; `ht_aes128/` và `ht_aes128_256/` chứa đặc tả và tài liệu của từng batch core. `ht_aes_gcm_acc/` chứa bản nháp đặc tả bộ tăng tốc AES-GCM bao quanh core `ht_aes128_256`. Tiêu chuẩn dùng chung nằm trong `shared/references/`.
